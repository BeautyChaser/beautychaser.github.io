# 维护与交接资料

这个目录供项目所有者和后续接手的模型共同使用。它保存项目知识，不需要安装特定的 AI 工具。

| 文件 | 用途 |
| --- | --- |
| `../AGENTS.md` | 自动发现的项目维护入口与基本约定 |
| `PROJECT_CONTEXT.md` | 网站身份定位、技术栈、目录与关键设计决策 |
| `MAINTENANCE.md` | 开发、构建、验证、发布、换机与排错步骤 |
| `STYLE_GUIDE.md` | 经用户要求确定的风格方向、视觉约定与文案边界 |
| `NEWS_SYNC.md` | AI 按文章链接收录、平台主页、可用订阅与发布流程 |
| `HANDOFF.md` | 最近一次任务的实际状态、验证结果与后续事项 |

换电脑后先克隆仓库、阅读本目录，再按 `MAINTENANCE.md` 安装依赖。换模型时，可以直接将以下说明发给新模型：

> 请先阅读仓库根目录的 AGENTS.md 和 agent/ 下的维护资料，再根据我的需求维护。这个仓库必须同时保留源码和根目录 GitHub Pages 输出，网站入口是根目录 index.html。

维护时按内容更新对应文件。`PROJECT_CONTEXT.md` 保存长期约定，`HANDOFF.md` 保存当前状态；不要将历史推测写成已完成事实。涉及未来功能的想法应明确标记为待实现。
